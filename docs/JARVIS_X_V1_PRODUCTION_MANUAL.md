## 💻 CLI Command Reference

| Command | Purpose |
|---|---|
| `python -m jarvisx cert` | Runs full production readiness certification (Security, Chaos, Benchmark). |
| `python -m jarvisx benchmark` | Profiles internal runtime latencies and memory footprint. |
| `python -m jarvisx doctor` | Full health diagnostic across all 5 SQLite databases. |
| `python -m jarvisx security status` | Displays vault encryption state and audit chain integrity. |
| `python -m jarvisx security audit` | Verifies cryptographic SHA-256 hash-chain integrity. |
| `python -m jarvisx backup create` | Creates point-in-time snapshot with SHA-256 checksums. |
| `python -m jarvisx evolution` | Displays self-improvement events from the Evolution Ledger. |
| `python -m jarvisx team "<mission>"` | Dispatches mission to Alfred and the specialized multi-agent fleet. |
| `python -m jarvisx proactive` | Runs trajectory simulation and proactive initiative checks. |
| `python -m jarvisx personal_os status` | Displays human life goals, mastery levels, and habit streaks. |
