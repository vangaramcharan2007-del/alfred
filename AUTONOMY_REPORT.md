## 3. Codebase Intelligence & Trust Layer

- **Codebase Understanding (`src/jarvisx/codebase/`)**: AST symbol indexing (`SymbolIndex`), import scanner (`RepositoryScanner`), module dependency graph (`DependencyGraphBuilder`), and change impact analyzer (`ChangeImpactAnalyzer`).
- **Ambiguity Detection**: Evaluates vague user requests (e.g. `"Build me an app"`) and prompts for missing requirements (Platform, Features, Database).
- **Model Intelligence**: Dynamic LLM routing across local Ollama models (`qwen2.5-coder`, `deepseek-coder`, `llama3.2`) based on task complexity, context length, and latency.
- **Human Trust Interface**: Visual CLI output for `jarvis mission "<task>"` presenting Mission Understanding, Plan steps, Confidence score, Risk level, and Approval status.
